SCREEN 2 · INTELLIGENT ACCIDENT DETECTION ENGINE

Multi-sensor evaluation (MPU6050 acceleration, peak impact, gyro orientation/fall, GPS speed drop & rider inactivity)
SIMULATED EVALUATION
MINOR EVENTSmall bump / brief handling tap · Log only, no automatic emergency alert
POSSIBLE SERIOUS ACCIDENTModerate impact + tilt/deceleration · Rider check-in with cancellation window
SEVERE ACCIDENTStrong sustained impact + fall motion + speed drop · Immediate emergency response
1. Speed Before Accident—Last valid pre-impact speed
2. Speed After Event—Post-impact GPS reading
3. Change in Speed (Δv)—Speed drop indicator
4. Estimated Deceleration—Requires valid Δt
5. Peak Acceleration—MPU6050 resultant |a|
6. Impact Event Duration—Filters <55 ms false spikes
7. Orientation & Inactivity—Gyro tilt / stillness check
8. Classified SeverityNORMALAwaiting event
Engineering Note: Speed is one risk indicator, not proof of injury severity. This system does not diagnose medical injuries or invent injury percentages; real deployment thresholds must be calibrated through controlled physical testing.
